# Optional extras for ashd.py, the always-on daemon.
#
# Everything here degrades gracefully -- ASH runs without any of it, it just
# perceives less. Included in the offline kit by default because the whole
# point of an air-gapped box is that you cannot add these later.
# Build without them: build_usb.ps1 -SkipDaemonExtras
#
# Deliberately NOT here:
#   faster-whisper  -- local ASR, but it needs its own Whisper model downloaded
#                      into the HF cache. Add both if you want offline speech
#                      input; without it, transcription falls back to Google's
#                      recognizer, which uploads audio and which
#                      PrivacyPolicy.require_local_asr blocks by default.

psutil                  # system sensor, pid liveness, process names
mss                     # fast screenshots
sounddevice             # audio capture
webrtcvad               # voice activity detection
opencv-python           # webcam capture + motion gating
pyautogui               # synthetic keyboard/mouse (dry-run by default)
pyperclip               # clipboard
pyserial                # serial sensors and motor control
