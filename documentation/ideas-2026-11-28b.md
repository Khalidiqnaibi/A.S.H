## Proposals

### A. Make the network honest and out of the way
1. **One network layer (`net.py`).** `online()` (cached for 20 s, a TCP probe), `get(url, why)` returning `ok / refused / empty / down` -- never a bare exception. Facts, define, weather, research, learnweb,
   canrun, inbox, pipeline's page fetch all use it. The words ASH says follow the result: "no connection", "the service refused me (bot check)", "it had nothing". Test: every module's fake `get` returns each of the four.
2. **Network work on a worker.** A tiny `jobs.py`: `run_async(label, fn, say_when_done)`. The handler says "Checking Steam..." / "Learning that..." at once, the loop keeps listening, the answer is spoken when ready
   (and "what are you doing?" lists it, "stop that" cancels -- the pipe runner already has both). Moves `learnweb.learn`, `machine.can_run`, `facts`, `define`, research onto it.
3. **What left this computer, today.** `state/network.jsonl`: one line per outbound request (host, why, bytes, what was sent -- the query text only). "What did you send out today?" reads it. It is the answer to "only when asked" being checkable, and it fits the privacy page.
4. **A search layer with memory.** One place that tries DuckDuckGo, Bing, Wikipedia (as `learnweb.web_fetch` does now), drops ads and download pages (28 Nov: the first Bing snippet for "chunk tasks" was an Opera ad), caches a day, and is used by learn, research and `look up`.

### B. Say it by sound: repair what was heard against what ASH knows
5. **Phonetic repair (`phonetic.py`).** For a short imperative that no rule took, map each word to the nearest word in ASH's own vocabulary by sound (a small metaphone plus edit distance) -- app names (Opera, Discord, Claude), command words (unpause, full screen, borderless), the user's names --
   and re-run the rules on the repaired line when the change is small and unambiguous; otherwise ask "Did you mean *switch to Opera*?" (the yes/no loop exists and teaches the chooser). "Obra" -> Opera, "unbossed" -> unpause, "Indiscone" -> Discord.
6. **Learn from the repeat.** When a command fails or is corrected and the person says it again, keep (what was heard -> what worked) in `misheard.py` automatically, and feed it to the recogniser's hints. Today the pairs are only learned when told.

### C. One list of apps, one way to say it
7. **App registry.** `apps.py`: one list built from desktop.apps, inventory (Start menu, Store, Steam, Epic) and the running windows, with aliases ("Claude desktop", "the browser" -> your default, "code" -> VS Code) and the ones you ask for most first.
   Desktop open/switch/close, inventory, the pipe action stages and the recogniser hints all read it. "Close Claude" and "minimise Claude" work for Store apps (today only switch and open do).
8. **Window moves for any app.** "Put Opera on the left and Discord on the right" exists for known apps (lifelog); extend to the registry, and "go back to what I was doing" (the window before the last switch).

### D. More stages in the pipes
9. **Every feature is a stage.** Add notes ("note that down" exists), reminders ("remind me in ten minutes"), timers, learn-from-web, search-and-open, "tell me the weather", "take a photo", "read the page" as action/data stages, so "open the lease and read it to me, then remind me tomorrow to sign it" is one sentence.
10. **Conditional and repeating pipes.** "When the download finishes, open it" (watch.py already knows downloads), "every morning at nine do my study setup" (skills + reminders), "after this video, close Opera".
11. **Name and share them.** Pipes saved by name exist; add "what pipes do you have" in the morning briefing, and export with the skills pack.

### E. Can-run and the machine, further
12. **A real comparison.** Add the CPU (a small table like the graphics one), video memory (nvidia-smi gives it; the Steam page often lists "4GB VRAM"), and free disk space against "Storage: 70 GB", so the answer can say which one is short.
13. **What could this run?** "What games on my wishlist can I run" / "what can this PC run well" from the inventory's own games and the Steam page; "what would help most" (memory, card) from the shortfalls.
14. **Apps, not just games.** The same for Photoshop, Blender, DaVinci (their vendors' requirement pages) -- only online, only on request, named as from that page.

### F. Learning from what you watch
15. **Learn from this video.** You taught it that "see how something works" means a YouTube video. With the page in front (tabs sensor) and online: fetch the video's captions (YouTube's own timed-text track, no key), summarise extractively (pipeline.summarize), break into concepts (learnweb.concepts) and ask "is that right?".
    Connects habits, the page reader, learnweb and the concept graph; nothing runs offline, and the whole thing is a pipe: "learn from this video" = read the page | summarize | learn.
16. **Pronouns for the page in front.** "Pause this", "who is this channel", "save this video", "how long is this" using the window title and tab (the media control and `looking` pieces exist).

### G. Typing by voice, done properly
17. **Dictation mode.** "Start dictating" -> everything said is typed into the window in front until "stop dictating"; spoken punctuation ("comma", "new line", "question mark"), "scratch that" (undo the last phrase with Ctrl+Z), and a read-back on request. Uses the control executor's `type_text`; blocked windows stay blocked.
18. **Click by number.** When a text click is ambiguous (or there is no text), draw numbers over what the screen reader found and say "click 7" (the voice-access pattern); the OCR boxes are already read in `control.find_text`.

### H. Reliability you can see
19. **A health line.** One console strip: online / model loaded / prompt size and seconds of the last answer / mic hearing level / network jobs running. Same numbers `status()` already returns, drawn.
20. **A smoke test for what was added.** `tools/smoke.py` that exercises, against fakes, each rule added in the last week (keys, compound, inventory, can-run, learn) in one second, run at start-up in a copy: "I was updated: 12 new rules, all pass".
