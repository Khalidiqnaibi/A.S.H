## Ranked fixes and features

### A. Quick, no model needed

1. **Spell it.** "Spell X", "how do you spell X", "spell it again" -> "S, E, G, U, E" by rule. (Today: the model, 28 s, and wrong.)
2. **Define it.** "Define X", "what's the definition of X", "what does X mean", "what's another word for X" -> a dictionary source
   (Wiktionary REST `page/definition/<word>`, same switch and privacy rules as `facts.py`; the word only leaves the machine). The
   facts rule stops treating "definition of X" as an article title.
3. **Media control with a subject.** "Pause / unpause / resume / play / stop the video / the YouTube video / the movie / the tab", "next
   video", "skip the ad": the same media keys `media.py` already sends, aimed at the player in front (`ActiveWindowSensor` knows it is
   Opera/YouTube/Stremio). Add the sound-alikes "unboss", "on pause", "unpaws".
4. **Look something up.** "Look up cat pics", "search for X", "search YouTube for X", "google X": opens the default browser on the search
   page (a URL, nothing else) through the desktop executor that already opens apps. Said back: "Searching for cat pics in Opera."
5. **Strip trailing offers** from model answers (`honest.py`/`system2`): a last sentence matching "What would you like to ...", "How can I
   assist you ...", "Is there anything else ...", "Let me know if ..." is dropped when something precedes it.
6. **Say the model notice once, ever.** Remember the choice (`state/llm.json`), start with it next time, say nothing; offer "set it for
   good" (writes `llm.model` to `daemon.json`).
